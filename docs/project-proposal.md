# 项目提案：宠物医院管理系统
## 项目名称
宠物医院管理系统
## 目标用户
宠物主人、医院医生、前台工作人员
## 优先实现业务场景
宠物主人线上提交就诊预约，前台审核预约，医生查看预约信息，完成基础就诊建档。
## 两个核心模型
1. Pet（宠物模型）：记录宠物名称、品种、年龄、疫苗、病史，关联宠物主人
2. Appointment（预约模型）：记录预约时间、宠物信息、接诊医生、预约状态

## 业务建模
### 核心业务流程
为宠物新增就诊记录，校验宠物合法性，保存就诊记录；支持根据宠物编号查询全部就诊记录。

### 业务实体及关系
实体 Pet（宠物）、Visit（就诊记录）。
Pet 与 Visit 是一对多关系：单只宠物可以拥有多条就诊记录，一条就诊记录只归属一只宠物，Visit 通过 petId 关联 Pet。

### Service业务校验规则
新建就诊记录时，必须校验petId对应的宠物是否存在。宠物不存在则抛出ResourceNotFoundException，禁止创建就诊记录。
