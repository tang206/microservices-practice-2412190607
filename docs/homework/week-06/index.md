# Week06 微服务拆分实验
## 实验内容
完成宠物医院管理系统单体应用的微服务领域拆分，按照领域边界拆分为至少3个独立微服务，遵循微服务数据隔离规范。

## 实现思路
以领域驱动思想划分边界，拆分为用户服务、宠物档案服务、预约就诊服务。每个服务使用独立数据库，只维护自身业务数据。服务之间只存储对方ID，通过HTTP接口获取外部数据，不创建跨库外键，避免服务强耦合。

## 服务拆分说明
拆分后的三个微服务：
1. user-service 端口8081，管理用户账号信息
2. pet-service 端口8082，维护宠物档案资料
3. appointment-service 端口8083，处理预约和病历

预约服务在新增预约、查询预约详情时，远程调用用户服务和宠物服务接口校验、拉取信息；用户服务和宠物服务之间不直接互相调用。

## 关键结论
本次拆分实现业务解耦，各服务可以独立迭代部署。数据隔离降低数据库层面耦合，符合微服务设计要求。
